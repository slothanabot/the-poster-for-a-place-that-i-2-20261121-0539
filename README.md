A make.fun entry for **The Poster for a Place That Isn't There**
(`the-poster-for-a-place-that-i-2-20261121-0539`).

`main.py` (Python 3.13, standard library only) draws a travel poster for
**NIMBARA**, a city that floats above a sea of clouds, and writes it to
`/output/entry.png` — a 1024×1024 PNG, deterministic, no network, no fonts
(letters are hand-drawn vector glyphs), no external files.

The poster's landmark is the **Lantern Bridge**: a wooden arc strung between
two floating islands, hung with glowing lanterns, under the beacon of the
Skyharbour tower — with hot-air balloons drifting past at sunset.

## Run

```sh
python3 main.py
# writes entry.png to $MAKEFUN_OUTPUT_DIR (or /output)
```
